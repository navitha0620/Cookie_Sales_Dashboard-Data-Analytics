#  Cookie Sales Analysis Dashboard | Power BI

##  Project Overview
The Cookie Sales Analysis Dashboard is an interactive Power BI project designed to analyze cookie sales performance across countries, products, and time periods. The dashboard transforms raw sales data into clear and actionable business insights, helping stakeholders understand revenue trends, top-performing products, and overall business performance.

---
##  Key Business Insights
- Canada and France generate the highest profit.
- Chocolate Chip is the top-selling cookie product.
- Sales are strongest at the beginning of the year and gradually decline.
- Overall performance summary:
  - Total Revenue: 4.69M  
  - Total Units Sold: 1.13M  
  - Population growth from 2018 to 2019 indicates positive market potential.

---
##  Dashboard Highlights
- Interactive slicers for Country, Product, and Month.
- Visual storytelling using bar charts, line charts, donut charts, and KPI cards.
- Clean and user-friendly layout focused on quick insights.

How to Use
- Open the <a href="https://github.com/navitha0620/Cookie_Sales_Dashboard-Data-Analytics/blob/main/Cookie_Dashboard.pbix">Cookie Sales Dashboard.pbix</a> file in Power BI Desktop.
- Ensure the Cookie Sales Excel (Kevin) file is in the same folder.
- Click Refresh to load the latest data.
- Use slicers to filter insights by Country, Product, and Month.
- Explore visuals to analyze sales trends, profit, and performance.
